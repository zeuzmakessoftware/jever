# Design direction

The concept image was generated before application code. The artwork follows Typesafe.ai's pink halftone fields, one-bit pixel motifs, black title strips, and early desktop window compositions.

The product uses Geist for readable interface text and IBM Plex Mono for compact metadata. Borders and 3–5px corners unify controls; the ornamental window alone uses a deliberate offset shadow. Motion is limited to state feedback, with reduced-motion support.

Design settings: variance 5, motion 2, density 5. This is a product workspace, so marketing-page rules do not drive the information architecture.

The implementation adapts the concept to Jev's actual capabilities. It shows typed decisions and real provider confidence rather than invented prose or reasoning. The landing artwork and application icon were separately AI-generated and stored locally.
