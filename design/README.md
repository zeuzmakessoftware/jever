# Design direction

The concept image was generated before application code. The artwork follows Typesafe.ai's pink halftone fields, one-bit pixel motifs, black title strips, and early desktop window compositions.

The current interface was simplified after the initial concept: a quiet sidebar, a short welcome prompt, and a message bar. The Questions button opens a compact editor inside the composer flow. Advanced controls and answer metadata remain behind disclosures. Decorative banners, uppercase labels, and the permanent question panel were removed.

The product uses Geist for interface text and IBM Plex Mono for structured data. Subtle borders and a neutral palette keep attention on the conversation. Motion is limited to state feedback, with reduced-motion support.

The original concept (`jever-concept.png`) and generated artwork (`dither.png`) remain here as design history. The artwork is no longer shipped in the main interface. The separately generated application icon remains in `build/icon.png`.
